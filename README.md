# freecodecampcrawler

A web crawler built with Google Apps Script and Google Sheets to scrape blog posts from freeCodeCamp 'https://www.freecodecamp.org/news'.

Function: 
1. Find new blogs.
2. Store unique Post Urls
3. Scrape Blog Title, author, post date, author description, blog content.

Libraries: https://cheerio.js.org/
